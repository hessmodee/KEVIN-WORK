## Trial gate

A skill is **READY FOR OWNER TRIAL** only when all of the following are true at trial time:

1. Benchmark is fresh PASS 30/30, critical 0.
2. Skill Lab and Engineering/Support lanes show healthy current evidence.
3. The exact composite skill is present in the proven registry/receipt evidence; a manifest alone is not proof.
4. Requested inputs contain no customer PII, passwords, API keys or confidential dealership data.
5. Output stays inside the skill's reviewed GREEN primitives (currently artifact creation such as spreadsheet/text for this trial set).
6. Kevin records the produced artifact identity and a semantic verification receipt; a model message alone does not count.
7. A replay or second representative owner trial is used to strengthen repeatability evidence.

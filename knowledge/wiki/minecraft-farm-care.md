## Villager-like loop

1. Use Matt's existing plots unless he asks to expand.
2. Keep farmland hydrated (water within 4 blocks).
3. Hoe only agreed dirt/grass.
4. Plant what Matt specifies (wheat, carrots, potatoes, beetroot).
5. Harvest mature only; replant same crop immediately.
6. Return extras to storage only if Matt says so.
7. Protect fences/animals/composters; no trampling shortcuts.
